## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/vardhan23v/agentic-ai.git
cd agentic-ai
```

### 2. Install Dependencies

```bash
pip install jupyter pandas
```

### 3. Start Jupyter Notebook

```bash
jupyter notebook
```

Open any `.ipynb` file and start experimenting.
